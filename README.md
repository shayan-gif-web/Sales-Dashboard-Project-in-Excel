# Sales Dashboard Project in Excel

An Excel sales-analysis project that summarizes order revenue, cost, profit, regional performance, and salesperson results. The workbook also demonstrates lookup and conditional aggregation formulas.

## Business Questions

1. Which region generates the highest revenue?
2. How does revenue vary by month and product category?
3. Which salesperson contributes the most revenue?
4. What are the total profit and overall profit margin?
5. How can lookup and conditional aggregation formulas support routine reporting?

## How to Use

1. Download `project1_sales_dashboard.xlsx` from this repository.
2. Open it in Microsoft Excel.
3. Review the `Dashboard`, `Pivot table & charts`, `Vlookup & Xlookup`, and `sumif & countif` sheets.
4. Use the region slicer, if available in your Excel version, to filter the regional view.
5. Check the source data and formulas before using the displayed metrics in a business report.
